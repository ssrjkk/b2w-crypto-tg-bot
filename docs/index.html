Возможности

Шесть опор платформы

B2W Crypto собирает рыночные данные, портфель и уведомления в одном окне Telegram — а учебная модель позволяет разбираться в рынке без риска.

Рынок в реальном времени

Котировки и рыночная аналитика приходят по WebSocket — без обновления страницы и ручных запросов.

Портфель и распределение

Активы, доли и стоимость собраны в одном экране: видно, из чего складывается портфель.

Уведомления и алерты

Задайте условие по цене — платформа сообщит, когда оно исполнится. График можно закрыть.

Контроль риска

Лимиты и стоп-условия по позициям видны до того, как решение станет необратимым.

Mini App интерфейс

Весь интерфейс живёт внутри Telegram: Mini App открывается поверх чата, отдельное приложение не нужно.

Учебная модель

Платформа работает с учебными данными и не проводит реальных сделок: это среда для обучения, а не брокер.

Процесс

Один цикл — четыре шага

Путь данных внутри платформы: от тикера до осознанного решения.

1

Рыночные данные

WebSocket-поток доставляет цены и движения рынка в реальном времени.

2

Портфель

Котировки складываются в портфель: доли активов и общее распределение.

3

Уведомление

Коснулась цена заданного порога — алерт приходит прямо в чат.

4

Контроль риска

Лимиты и стоп-условия видны заранее; решение остаётся за человеком.

Запуск в пять строк

Склонируйте репозиторий, установите зависимости и поднимите API. Токен бота и параметры окружения описаны в README.

Python · Telegram · WebSocket

Терминал 
git clone https://github.com/ssrjkk/b2w-crypto-tg-bot.git
cd b2w-crypto-tg-bot
pip install -r requirements.txt
# .env: TELEGRAM_BOT_TOKEN, DATABASE__PATH, REDIS_URL — шаблон в README
alembic upgrade head
uvicorn app.api.main:app --host 0.0.0.0 --port 8000
